# 💻 CareerLens Frontend

> **React 18 + Vite + Tailwind CSS (Neumorphic UI)**

For the full system setup and backend configuration, refer to the [Main README.md](../README.md).

---

## 🚀 Quick Start

```powershell
# 1. Install dependencies
npm install

# 2. Setup environment variables
copy .env.example .env

# 3. Start Vite development server
npm run dev
```

* **Local Development URL:** [http://localhost:5173/](http://localhost:5173/)
* **Default Backend API Target:** `http://localhost:8000/api`
